# v0.3 Release Candidate Bundle

Status: ready for review / not final release

## Purpose

This bundle summarizes v0.3 release-candidate evidence for human / ChatGPT
review. It does not declare v0.3 final release and does not patch missing
functionality.

## Candidate Summary

v0.3 advances WorldEngine from the v0.2 recursive schema foundation toward a
generic WorldSpec loader and an optional inert runtime context bridge while
preserving the v0.1 runtime scaffold.

The candidate is reviewable because package evidence through 0.3.6 records:

- loader contract documentation.
- minimal generic WorldSpec loader implementation and focused tests.
- runtime context bridge contract documentation.
- minimal optional runtime context bridge implementation and focused
  compatibility tests.
- external fixture runner contract readiness.
- v0.3 evidence index and compatibility audit.

v0.3 is not final until 0.3.8 closeout after release-candidate review
approval.

## Explicit Non-Goals

v0.3 does not implement:

- Agent-in-World loop.
- memory or self-continuity substrate.
- world generation.
- projection API for external product surfaces.
- product UI or game UI.
- concrete demo world fixture.
- concrete external validation world.
- external fixture repository.
- external validation repository.
- story generation.
- NPC chat system.
- self-awareness claims.
