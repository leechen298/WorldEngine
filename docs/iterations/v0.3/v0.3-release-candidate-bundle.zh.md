# v0.3 发布候选包

状态：待评审 / 非最终发布

## 目的

本包汇总 v0.3 发布候选证据，供人工 / ChatGPT 评审。它不声明 v0.3 最终发布，也不
修补缺失功能。

## 候选摘要

v0.3 推动 WorldEngine 从 v0.2 递归 schema 基础走向通用 WorldSpec 加载器和可选
惰性运行时上下文桥接，同时保持 v0.1 运行时脚手架兼容。

该候选包可评审，因为截至 0.3.6 的包证据记录了：

- 加载器契约文档。
- 最小通用 WorldSpec 加载器实现和聚焦测试。
- 运行时上下文桥接契约文档。
- 最小可选运行时上下文桥接实现和聚焦兼容性测试。
- 外部 fixture 运行器契约准备。
- v0.3 证据索引和兼容性审计。

v0.3 在发布候选评审批准后的 0.3.8 收口前不是最终发布。

## 明确非目标

v0.3 不实现：

- 世界内 Agent 闭环。
- 记忆或自我连续性基座。
- 世界生成。
- 面向外部产品界面的投影 API。
- 产品 UI 或游戏 UI。
- 具体演示世界 fixture。
- 具体外部验证世界。
- 外部 fixture 仓库。
- 外部验证仓库。
- 剧情生成。
- NPC 聊天系统。
- 自我意识声明。

## 开放风险

- 评审者可能要求在 0.3.8 前补充新的运行时、API 或 UI 冒烟证据。
- 评审期间发现的 P1/P2 证据缺口必须阻塞最终收口，直到解决或被明确接受。
- 在 v0.3 最终收口前，v0.4 规划不得把本候选包视为实现许可。

## 最终收口前置条件

0.3.8 只能在以下条件满足后开始：

- 本发布候选包已评审并获批准。
- 所有 P1/P2 问题已解决或被明确接受。
- 发布措辞在最终收口前仍保持已规划 / 未发布状态。
- 最终收口记录变更文件、命令、测试结果、兼容性评审、范围评审、未解决问题和
