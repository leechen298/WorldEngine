# 契约

## 公共概念

- `WorldSpecLoader`：未来组件，接收受支持的通用 `WorldSpec` 输入并返回结构化
  结果。
- `WorldSpecInput`：来自受支持来源的单个候选 `WorldSpec` payload。
- `LoadedWorldSpec`：已校验的 `WorldSpec` 和中立来源元数据。
- `WorldSpecLoaderError`：描述不支持输入、解析、校验或输入输出失败的结构化
  错误。
- `WorldSpecLoaderResult`：一次加载器调用的成功或失败结果。

规范性公共契约是 `docs/contracts/worldspec-loader-contract.md`。

## 兼容性约束

- 现有运行时行为必须保持兼容。
- 现有 API 响应形状必须保持兼容。
- 现有事件、归档、参数、前端可见行为和旧路径行为必须保持兼容。
- 现有 `WorldSpec`、`WorldCell` 和 `EntityRef` schema 校验行为必须保留。
- schema 扩展保持追加式，除非后续已评审包明确允许破坏性变更。

## 允许变更

- 新增 `docs/contracts/worldspec-loader-contract.md`。
- 创建 0.3.1 迭代包文档。
- 更新 v0.3 里程碑索引及镜像，把 0.3.1 标记为 `待评审`。
- 仅为 0.3.1 状态一致性更新 v0.3 包计划及镜像。
- 定义加载器输入、输出、错误、校验和领域中立示例语义。
- 在 `review.zh.md` 中记录文档阶段验证证据。

## 禁止变更

- 不实现加载器代码。
- 不把加载器行为连接到 `RuntimeEngine`。
- 不修改 schema、运行时、API 路由、服务、前端、fixture、迁移或测试。
- 不创建具体 `WorldSpec` fixture 数据。
- 不创建外部 fixture 或验证仓库。
- 不发出事件，不写持久化记录，不创建归档快照，不应用参数。
- 不实现运行时桥接、世界生成、世界内 Agent 闭环、记忆、自我连续性、投影、
  剧情生成或 NPC 聊天行为。

## 验收要求

- 加载器契约明确说明接受的输入形式。
- 加载器契约明确说明成功输出字段。
- 加载器契约明确区分不支持输入、解析、校验和文件输入输出错误。
- 加载器契约要求通过现有 `WorldSpec` schema 或已评审包装器校验。
- 加载器契约说明已加载数据不是运行时上下文。
- 迭代包文档包含假设、未解决风险、验证命令和仅文档不跑测试的理由。
- 英文和中文里程碑镜像保持 0.3.1 状态同步。

## North Star 检查

本包保持 WorldEngine 的通用性。它定义的是结构化世界规格的引擎级加载边界，
并明确禁止具体演示世界 fixture、产品专用后端行为和外部验证内部细节。

## 范围外后续工作

- `0.3.2` 可在评审批准后实现最小加载器。
- `0.3.3` 可定义运行时上下文桥接契约。
- `0.3.4` 可在桥接契约评审后实现最小可选运行时上下文桥接层。
- 后续里程碑可处理 Agent 闭环、记忆、自我连续性、生成、投影和外部产品验证。
