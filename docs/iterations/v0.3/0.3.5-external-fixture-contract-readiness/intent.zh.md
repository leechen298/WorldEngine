# Intent

## 问题

v0.3 已经把 `WorldSpec` 加载和运行时上下文桥接推进到公开引擎边界。下一个风险是：
未来外部验证工作可能把具体样例世界、私有判定器细节、重置机制或产品特定假设
带进核心仓库。

WorldEngine 需要先明确外部验证样例运行器的公开契约，再进入可运行的外部验证。

## 意图

定义一个仅文档契约，让外部验证样例运行器把 WorldEngine 作为公开引擎表面消费：

- 公开 API 或 CLI 契约。
- schema 和导出契约文档。
- 已评审的加载器和运行时桥接契约。
- 脱敏验证报告模板。

该契约必须把外部样例仓库留在核心仓库之外，并要求报告使用抽象标识符和脱敏证据。

## 非目标

- 不实现外部验证样例运行器。
- 不创建外部样例仓库。
- 不添加具体样例数据或测试输入。
- 不添加具体外部世界名称、角色、地点、剧情规则或 seed data。
- 不添加私有判定器行为、重置 API 内部细节或 UI 选择器。
- 不修改运行时、schema、API、事件、归档、参数、前端、样例、迁移或测试实现文件。
- 不实现投影、世界内 Agent 闭环、记忆、自我连续性、剧情生成、NPC 聊天或世界生成。

## 验收

- 外部验证样例运行器契约存在，并且只使用公开 WorldEngine 概念。
- 迭代包文档完整并待评审。
- 迭代包 README 和 v0.3 里程碑索引将 0.3.5 标记为 `待评审`。
- 验证要求可通过文档检查测试。
- 假设和开放风险已明确记录。
