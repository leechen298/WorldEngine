# Contract

## 公开概念

- 外部验证样例运行器是 WorldEngine 的外部消费者。
- 公开契约表面包括已记录的 API 路由、CLI 契约、schema、契约文档、导出模板和
  脱敏评审证据。
- 脱敏验证报告是描述公开行为、但不泄露外部消费者内部细节的证据记录。

## 必需契约行为

本包必须：

- 新增 `docs/contracts/external-fixture-runner-contract.md`。
- 将外部运行器定义为消费者，而不是核心代码。
- 明确允许的公开消费表面。
- 要求脱敏验证报告遵循 `docs/validation-report-template.md`。
- 列出禁止泄露的细节。
- 仅使用抽象标识符。
- 保持所有示例领域中立。
- 让 v0.3 范围与加载器和运行时桥接证据一致。

## 允许变更

- 新增外部验证样例运行器契约。
- 创建 0.3.5 迭代包文档。
- 更新英文和中文 v0.3 里程碑索引与详细计划中的包状态。
- 添加只使用抽象标识符的仅文档示例。
- 在 `review.md` 记录文档阶段验证。

## 禁止变更

- 不修改运行时、schema、API、事件、归档、参数、前端、样例、迁移或测试实现文件。
- 不创建外部仓库。
- 不添加具体样例数据。
- 不添加具体外部世界名称、角色、地点、资源、剧情规则、地图数据、seed data
  或私有转录内容。
- 不添加 UI 选择器、隐藏重置 API 或私有判定器行为。
- 不实现产品验证应用。
- 不围绕某一个外部消费者收窄加载器或桥接层 API。
- 不在缺少当前会话证据时宣称运行时、构建、测试、E2E、UI smoke 或 Agent smoke
  行为已通过。

## 兼容性

这是仅文档包。它必须保持以下行为不变：

- 运行时。
- schema。
- 公开 API。
- 事件。
- 归档。
- 参数。
- 前端可见行为。
- 样例。
- 迁移。
- 测试。
- 旧路径 `backend/worldengine/`。

任何由本契约触发的未来实现，都必须进入单独评审过的迭代包，并且必须把需求描述为
通用引擎能力。

## 假设

- 0.3.2 加载器和 0.3.4 桥接层评审已经提供足够的公开契约上下文。
- `docs/validation-report-template.md` 仍是脱敏报告字段的来源模板。
- 未来外部验证样例运行器可以适配抽象 suite、target 和 scenario 标识符。

## 开放风险

- P3：未来外部运行器可能需要尚未记录的公开 CLI 或 API 细节。该缺口应记录为
  通用契约缺口，而不是用私有样例细节填补。
- P3：脱敏可能隐藏调试所需证据。后续包可能需要更结构化的脱敏证据 schema。
- P3：较早的 v0.3 文档中状态术语混用英文和中文；本包只更新自己负责的 0.3.5
  状态条目。

## North Star 对齐

本包通过保持 WorldEngine 的通用性，同时允许外部验证消费者练习公开引擎行为，
来支持北极星方向。它不会把核心仓库变成应用后端或样例仓库。
