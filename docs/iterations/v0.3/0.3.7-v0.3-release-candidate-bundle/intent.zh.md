# 意图

## 问题

v0.3 已有加载器、桥接层、外部 fixture 准备、证据索引和兼容性审计产物，但它们
分散在多个包评审和审计文档中。人工 / ChatGPT 评审需要一个发布候选包，把每个
声明映射到证据，并保持未实现范围清晰可见。

## 目标

创建一个发布候选证据包，清楚说明：

- v0.3 计划了什么。
- v0.3 实现或文档化了什么。
- 当前有哪些验证证据。
- v0.3 明确没有实现什么。
- 仍有哪些问题、假设和风险。
- 为什么最终发布收口推迟到 0.3.8。

## 非目标

- 不声明 v0.3 最终发布。
- 不关闭 0.3.8 工作。
- 不实现或修改运行时、schema、API、前端、fixture、迁移或测试行为。
- 不添加世界内 Agent 闭环、记忆、自我连续性、生成、投影、产品 UI、游戏 UI
  或外部验证仓库。
- 不添加具体演示世界、角色、地点、资源、剧情规则、种子数据、私有 fixture
  状态或应用专用后端逻辑。

## 为什么现在

0.3.6 已组装证据索引和兼容性审计，并记录没有未解决 P1/P2 阻塞项。里程碑计划
下一步要求在最终收口前准备发布候选包，让评审者决定 v0.3 是否可以进入 0.3.8。

## 北极星对齐

本包通过让 WorldSpec 加载器和惰性运行时上下文桥接的证据可评审，支持
WorldEngine 作为通用递归世界运行时；它不会把引擎变成具体产品界面，也不会声明
未来的 Agent、记忆、生成或投影能力。
