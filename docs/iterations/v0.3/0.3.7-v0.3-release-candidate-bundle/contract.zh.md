# 契约

## 公共概念

- 发布候选包：汇总 v0.3 证据和限制、但不声明最终发布的评审包。
- 最终评审包：从发布候选证据生成的人工 / ChatGPT 交接文档。
- 发布候选声明：v0.3 能力、边界或兼容性声明，必须映射到已有评审证据、
  审计证据或明确的限制状态。
- 证据来源：已完成的包评审、包契约、证据索引、兼容性审计、问题表、发布占位
  文档，或 0.3.7 会话中运行的命令。
- 阻塞问题：未解决的 P1/P2 问题；除非已解决或被评审明确接受，否则会阻塞最终
  收口。

## 兼容性约束

- 运行时行为不得改变。
- schema 行为和验证行为不得改变。
- API 路由行为和响应形状不得改变。
- 事件存储、事件分页、归档、参数和前端可见行为不得改变。
- fixture、迁移和测试实现文件不得改变。
- 旧路径 `backend/worldengine/` 行为不得改变。
- 发布候选文档不得声明最终发布状态。
- 声明必须区分已规划、已文档化、已实现、已测试、未实现、部分、历史和问题
  状态。
- 未解决 P1/P2 必须保持可见，并阻塞 0.3.8 最终收口，直到解决或被明确接受。

## 允许变更

- 创建 `docs/iterations/v0.3/0.3.7-v0.3-release-candidate-bundle/**`。
- 新增 `docs/iterations/v0.3/v0.3-release-candidate-bundle.md`。
- 新增 `docs/iterations/v0.3/v0.3-release-candidate-bundle.zh.md`。
- 在本包目录新增最终评审包文档。
- 用文档验证证据更新本包 `review.md` 和 `review.zh.md`。
- 更新 v0.3 里程碑索引和 v0.3 计划中 0.3.7 的状态字段。
- 仅当发布候选组装发现新的或变化的 P1/P2/P3 问题时，记录到
  `docs/iterations/v0.3/findings.md`。
- 运行只读仓库搜索、文件检查、发布状态表述检查、证据可追溯检查和文档
  健康检查。

## 禁止变更

- 不修改运行时服务、schema、API 路由、事件日志行为、归档行为、参数行为、
  前端行为、Agent 行为、持久化或应用装配。
- 不修改测试、fixture、迁移或 `backend/worldengine/`。
- 不实现加载器、桥接层、世界内 Agent、记忆、自我连续性、生成、投影、外部验证、
  产品 UI、游戏 UI、解析器或因果行为。
- 不创建外部仓库或加入外部验证内部细节。
- 不添加具体世界名称、地图、角色、地点、职责、资源、剧情规则、种子数据、
  UI 选择器、私有运行器状态或应用专用后端逻辑。
- 除非本会话实际运行了对应命令或流程，否则不声明测试、构建、运行时行为、
  API 行为或前端行为通过。
- 不标记 v0.3 最终发布，也不标记 0.3.8 完成。

## 验收要求

- `docs/iterations/v0.3/v0.3-release-candidate-bundle.md` 和 `.zh.md` 存在，
  并汇总范围、包状态、证据、兼容性、限制、假设、未解决问题和最终收口前置
  条件。
- `final-review-bundle.md` 和 `.zh.md` 存在于本包目录，并遵循最终评审包模板结构。
- 每个发布候选声明都映射到具体证据来源，或标记为已规划、未实现、部分、历史
  或问题。
- P1/P2/P3 问题明确列出，并说明是否阻塞最终收口。
- 发布状态表述检查确认没有声明最终发布。
- 具体演示锚点扫描通过，或残留项被分类为历史 / 仅评审 / 假阳性。
- 变更文件限制在批准的文档路径内。
- 英文和中文镜像在包文档、候选包、最终评审包和状态更新上保持同步。

## 北极星检查

本包通过让 v0.3 加载器和运行时桥接证据可评审，保护 WorldEngine 作为通用递归
世界引擎的定位，同时保留未来 Agent、记忆、生成和投影边界。

## 范围外后续

- 0.3.8 只能在 0.3.7 发布候选评审批准后执行最终收口。
- v0.4 规划只能在 v0.3 收口门禁之后使用 v0.3 证据。
- 新的运行时、API、前端、E2E 或构建验证只有在本包显式运行时才属于本包评审；
  否则历史证据必须继续标记为历史。
