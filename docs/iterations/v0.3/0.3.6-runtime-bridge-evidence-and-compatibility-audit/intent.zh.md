# 意图

## 问题

v0.3 已有独立的加载器、桥接和外部样例契约准备包。发布候选工作之前，项目需要一个
可评审的审计，把这些证据连接到兼容性表面和 v0.4 交接准备度。

## 目标

创建证据索引和兼容性审计，区分已实现行为、已文档化契约、已测试兼容性、缺失证据和开放发现。

## 非目标

- 不实现或修补加载器行为。
- 不实现或修补运行时上下文桥接行为。
- 不增加 API、前端、schema、样例、迁移或测试实现变更。
- 不启动 v0.4 世界内 Agent 工作。
- 不声明 v0.3 发布状态。

## 为什么现在做

0.3.6 位于外部样例契约准备和发布候选包之间。它判断 v0.3 证据是否足够清晰，
可以进入发布候选评审。

## 北极星对齐

本包通过保持 WorldSpec 到运行时桥接的通用性、证据支撑和兼容性来支持北极星。
它保持 WorldEngine 作为引擎基础，而不是把项目收窄成具体验证世界或应用后端。
