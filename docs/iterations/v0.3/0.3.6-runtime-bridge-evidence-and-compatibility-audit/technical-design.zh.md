# 技术设计

## 当前状态

v0.3 已完成到 0.3.5 的包评审。加载器和桥接实现证据位于各包 review 文件中，
milestone index 仍把 0.3.6 列为已规划。

## 契约对齐与不变量

本包只修改文档。它聚合既有 review 证据，并保持所有实现表面只读。

审计必须保持以下不变量：

- 不修改运行时、schema、API、前端、样例、迁移或测试实现文件。
- 证据声明引用既有 package review 记录的命令，或本次文档会话实际运行的命令。
- 缺失或间接证据要记录为发现或风险。
- v0.4 交接准备度是规划准备度，不是实现许可。

## 拟定文档结构

- `evidence-index.md`：逐包证据矩阵和兼容性表面索引。
- `compatibility-audit.md`：验收问题结果、兼容性分类、发现、假设和发布候选验证要求。
- 0.3.6 包文档：意图、契约、技术设计、测试计划、执行计划和 review 证据。
- 所有新增审计和包文档的中文镜像。

## 受影响表面

- 文档：v0.3 迭代文档和包状态索引。
- 运行时：不触及。
- API：不触及。
- Schema：不触及。
- 前端：不触及。
- 测试/样例/迁移：不触及。
- 旧路径 `backend/worldengine/`：不触及。

## 数据模型 / Schema 变更

无。

## 运行时 / 服务设计

无。本审计不添加服务行为。

## 兼容性

兼容性从既有包证据评估：

- 0.3.2 用聚焦后端测试证明 data-only 加载器。
- 0.3.4 用聚焦桥接和兼容性测试证明可选惰性运行时上下文。
- 0.3.5 用文档契约证明外部样例消费者边界。

## 风险

- 既有 review 证据可能遗漏某个兼容性表面；审计会把它记录为缺失或间接证据，而不是假定成功。
- 更广的前端可见行为可能需要额外发布候选 smoke 覆盖。
- 外部运行器报告后续可能需要更严格的机器可读形状。
