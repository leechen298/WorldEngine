# v0.9 Plan

英文镜像：`v0.9-plan.md`。

Status：reviewed / 0.9.9 implementation complete / verification passed

## Version Name

LLM-backed World Lifecycle Foundation

## Objective

建立第一个由 WorldEngine 拥有 LLM 行为的版本：它能从用户基础世界观生成可运行世界，能用
明确规则引导 bounded world evolution，能把用户 direction 接收为 world-level guidance，能
暴露 brain-inspired public Agent continuity 和 memory-consolidation evidence，能把 narrative
和 diagnostic conversation surfaces 保持在 canonical world mutation 之外，并且能通过
LLM-backed autonomous evidence contracts 验证。

## Planning Authority Boundary

本文件是 v0.9 parent roadmap 和 planned package specification。下面的 `0.9.x` sections
只是 route-map specs，不是 active child contracts、implementation authorization、evidence
execution authorization 或 provider live-call authorization。

任何 `0.9.x` child 开始前，agent 必须在当时创建或确认该 child 的 complete document set，
然后通过 review gate。

## Version Boundaries

v0.9 可在 reviewed child authorization 后定义或实现：

- 通过 WorldEngine-owned configuration 进行 provider live smoke。
- redacted provider evidence。
- public LLM-backed worldview ingestion 和 world model generation。
- generated world rules、parameters、constraints、validation metadata 和
  runtime-readiness semantics。
- generation 后立即检查和 bounded runtime 后检查的 worldview fidelity。
- 按 ticks、world-time duration、pause、resume 和 provider/cost limits 进行 bounded run
  controls。
- queued world-level guidance 形式的 natural-language world direction。
- rule-linked parameter evolution 和 event legality。
- brain-inspired Agent continuity contracts，覆盖 perception、working 或 short-term memory、
  long-term memory summaries、personality summaries、skill summaries、intent states、behavior
  和 event reactions。
- sleep、rest 或 low-activity consolidation cadence，让 memory、personality 和 skill updates
  可以跨多个 ticks 沉淀，而不是强制每 tick 发生。
- external narrative projection 和 out-of-world diagnostic conversation boundaries，用于 inspection
  和 validation。
- LLM-backed autonomous checker/schema/fixtures/scorecard support。
- Validation Client consumption 所需的 public evidence handoff contracts。

v0.9 不得实现：

- Validation Client provider key management 或 direct LLM calls。
- concrete game/application worlds、names、maps、characters、resources、story
  rules、private validation scenarios 或 application-specific backend logic。
- product UI、game packaging、Steam/native distribution、app deployment 或 external
  validator implementation。
- evidence 中的 raw prompt、raw response、raw provider trace、raw thought、
  chain-of-thought、private Agent memory、private goals、hidden context 或 secrets。
- 绕过 rules 和 world state 的 direct user-imposed final facts。
- automatic per-tick personality、long-term memory 或 skill mutation。
- external player-to-Agent diagnostic conversation 默认作为 in-world dialogue、world timeline
  content 或 Agent memory。
- narrative text generation 修改 canonical world state。
- `backend/worldengine/` 下的新 runtime features。
- 没有 checker/scorecard/second-Agent review evidence 时声明 LLM-backed lifecycle PASS。

## Capability Boundary Split

| Capability | v0.9 owns | Validation Client owns |
| --- | --- | --- |
| Provider config and calls | yes | no |
| API key storage | environment only | no |
| Worldview input capture | public contract | UI operation surface only |
| World model generation | yes | no |
| User direction interpretation | yes | input/display only |
| Runtime tick/time control | yes | command surface only |
| Event legality | yes | no |
| Agent continuity evidence | yes, public summaries and consolidation cadence | display/export only |
| Narrative projection | public projection contract | display/export only |
| Diagnostic Agent conversation | out-of-world diagnostic contract | UI operation surface only |
| Authoritative evaluation | checker/scorecard | no |
| Evidence export format | public contract | export carrier |

event reaction records、multi-round action tests、redacted evidence artifacts。

Forbidden changes: 不记录 raw thought、raw chain-of-thought、private memory payload、private

Exit criteria: public evidence shape 足以让后续 `0.9.10` checker package 区分 persistent
autonomy/consolidation evidence、one-off scripted action 和 per-tick mechanical mutation。
Checker fixtures、scorecards 和 checker execution 仍由 `0.9.10` 拥有。
