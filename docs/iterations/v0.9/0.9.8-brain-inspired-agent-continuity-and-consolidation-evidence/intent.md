# Intent

Chinese mirror: `intent.zh.md`.

## Problem

v0.9 now has provider readiness boundaries, LLM-backed world creation shape,
world rule parameters, worldview fidelity checks, bounded runtime controls,
world direction boundaries, and rule-linked event legality. It still lacks a
public way to prove that an Agent is more than a one-off scripted action.

Without public continuity evidence, later LLM-backed validation cannot
distinguish persistent Agent autonomy from a client-supplied action, a per-tick
mechanical mutation, or hidden private reasoning.

## Product Intent

This package creates the first minimal public Agent continuity and
consolidation boundary. It should expose reviewable artifacts for perception,
short-term continuity, long-term summary references, personality and skill
summary references, intent/no-intent/rest states, event reactions, and
sleep/rest/low-activity consolidation phases.

The package is not a consciousness claim, full neuroscience model, narrative
projection system, diagnostic dialogue bridge, checker fixture package, or
frontend feature. It is a generic engine boundary for public Agent continuity
evidence.

## User Value

- Validators can inspect whether Agent behavior persists across time.
- Later checker work can judge public continuity evidence without reading raw
  prompts, raw thoughts, or private memory.
- WorldEngine can show sleep/rest/consolidation cadence without pretending
  personality, long-term memory, or skill state mutates every tick.
- Future narrative and diagnostic surfaces can consume public summaries
  without mutating canonical world state or Agent memory by default.

## North Star Alignment

WorldEngine's north star includes agents that live in worlds, accumulate
memory, change through feedback, and form engineered pseudo-self continuity.
This package advances that direction while preserving the explicit boundary
that WorldEngine does not claim real consciousness.

## Non-Goals

- No raw thought or chain-of-thought.
- No private memory payload export.
- No private goals or hidden context.
- No live provider interpretation.
- No checker execution or fixture changes.
- No external validation.
- No frontend or Validation Client changes.
- No narrative projection or diagnostic dialogue.
- No durable scheduler or background worker.
- No automatic per-tick personality, long-term memory, or skill mutation.
- No `backend/worldengine/` work.
