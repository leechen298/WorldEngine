# 意图

## 问题 / 目的

v0.7 最终收尾只是历史证据。后续代码审查记录了 3 个 P1 和 2 个 P2
检查器 / Schema 阻断项，阻止 clean pass、外部套件 PASS、投影就绪 PASS
和产品就绪 PASS。

本包的目的，是窄范围修复这些阻断项，然后重新运行必要验证，判断 v0.7
是否可以诚实地从 partial pass 推进到 clean pass。

## 为什么现在做

用户要求将 v0.7 推进到 clean pass。若把不可靠的就绪检查器带入 v0.8，会削弱
v0.7 应建立的公共证据边界。

## 与路线图的关系

v0.7 负责外部验证就绪和投影消费者就绪契约。
v0.8 负责第一个外部投影应用。本修复保持在 v0.7 内，不实现 v0.8。

## 非目标

- 不构建或验证投影应用。
- 不运行私有外部套件，也不导入外部验证世界。
- 不实现运行时 / API / 前端功能。
- 不运行或声明完整自主运行器 / 完整套件 PASS。
- 不修改无关的 `docs/iterations/v0.8/**` 工作树变更。

## 预期交接

如果全部 V07-CR 阻断项修复且验证矩阵通过，本包交付 clean-pass
v0.7 验证结果和修复后的检查器证据给 v0.8 规划。如果仍有阻断项，
则记录 partial pass 或 failed evidence，不做夸大声明。
