# Campaign Plan

Chinese mirror: `CAMPAIGN_PLAN.zh.md`.

Status: child package documentation review in progress

## Objective

Run v0.11 as a review-gated `/goal` campaign that makes the MVP world evolve
through rules, directions, events, diffs, and fidelity evidence.

The campaign objective is to make WorldEngine capable of:

- honestly classifying provider/worldview generation mode.
- attaching public structured rules and parameters to a session.
- queuing natural-language direction as world-level guidance.
- generating or selecting legal events during bounded runtime.
- applying public diffs with replay evidence.
- checking worldview fidelity before and after bounded runtime.

## Campaign Rules

- v0.11 must start from v0.10 session/debug handoff evidence.
- Planned `0.11.x` sections do not authorize implementation.
- User direction must be bounded world-level guidance.
- User direction must stay outside the world: no player item drops, direct
  detailed event triggers, or final-fact commands.
- Every applied event/diff must have public legality evidence.
- Validation Client remains external and consumes evidence only.
- MVP claims require current-session command evidence.

## Campaign Exit Criteria

v0.11 can close only when:

- active child packages are review complete or explicitly deferred.
- provider/worldview mode is honestly classified.
- rules and parameters are public and structured.
- user direction cannot directly impose final facts.
- direction examples prove direct death commands are rejected while
  lightning-risk guidance remains external pressure.
- events and diffs are rule-linked and replayable.
- worldview fidelity can be evaluated from public evidence.
- no P1/P2 finding remains without accepted rationale.

## Handoff

If v0.11 closes as PASS or acceptable PARTIAL, v0.12 starts from a rule-bound
running world and adds Agent continuity plus full Validation Client automation.
