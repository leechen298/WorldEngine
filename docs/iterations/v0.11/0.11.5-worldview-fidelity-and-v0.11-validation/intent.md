# Intent

Chinese mirror: `intent.zh.md`.

Status: documentation drafted / review pending

## Problem / Purpose

v0.11 needs an honest closeout. A rule-bound world can have valid rules and
legal diffs while still failing to preserve the public premise. This package
validates immediate and bounded-run worldview fidelity from public evidence and
records the v0.11 result.

## Why Now

`0.11.1` through `0.11.4` created the provider/worldview preflight, session
rules, direction boundary, and rule-compliant event/diff path. The final v0.11
child must now evaluate whether that evidence supports a rule-bound world
evolution closeout.

## Relationship To Roadmap

This package closes v0.11 only. It hands off to v0.12 for Agent continuity and
external automated validation. It does not claim complete MVP readiness.

## Non-Goals

- no provider live PASS.
- no external Validation Client PASS.
- no Agent autonomy PASS.
- no frontend implementation.
- no new rule/event/direction feature scope.
- no `backend/worldengine/` work.

## Expected Handoff

If v0.11 closes as PASS or acceptable PARTIAL, v0.12 starts from a rule-bound
running world with fidelity evidence and explicit exclusions.
