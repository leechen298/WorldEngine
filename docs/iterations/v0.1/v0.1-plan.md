# v0.1 Plan

Status: closeout documented

## Version Name

Runtime Scaffold

## Objective

Record what v0.1 actually contains and which tests currently validate it before
starting v0.2 Recursive World Foundation.

## Completed Capability Areas

- Monorepo scaffold and root dev workflow.
- Runtime state and step API.
- API response envelope.
- Runtime event log timeline.
- World module tree execution.
- World params dashboard and apply API.
- Params validation and dry-run policy.
- Archive snapshots and summaries.
- LLM-style params agent propose-and-apply path.
- Frontend dashboard integration and tests.

## Non-goals

- Recursive WorldCell runtime.
- WorldSpec loader.
- World generation.
- Agent-in-world perception/action loop.
- Agent memory and pseudo-self continuity.
- Reference village world.
- Game surface.

## Closeout Package

`0.1.1-v0.1-closeout` records the inventory and test evidence.

## Current Implementation Documentation Package

`0.1.2-current-implementation-docs` records the current backend, frontend,
API, and test implementation map. It is documentation-only and does not change
runtime behavior.

## Post-Closeout Verification Hardening Package

`0.1.3-e2e-agent-acceptance` adds deterministic dashboard E2E tests and an
Agent smoke evidence protocol. It is verification hardening only and does not
expand v0.1 runtime, product, WorldSpec, agent, or village capabilities.

## Codex Test Skills Package

`0.1.4-codex-test-skills` adds project-local Codex skills and sync tooling for
running E2E and Agent smoke workflows consistently. It is workflow guidance only
and does not expand runtime, product, WorldSpec, agent, or village capabilities.

## Project Agent Workflow Skills Package

`0.1.5-project-agent-workflow-skills` adds project-local workflow skills for
the two-stage iteration gate: one documentation-stage skill for drafting and
reviewing iteration packages, and one implementation-stage skill for executing
only approved code or mixed packages. It is workflow guidance only and does not
expand runtime, product, WorldSpec, agent, or village capabilities.

Status: review complete.

## Current-Code Test Case Expansion Package

`0.1.6-current-code-test-case-expansion` defines current-code E2E, Agent smoke,
and Codex/test-runner autonomous scenario contracts before implementing or
running more tests. It is documentation-only and does not add tests, execute
live Agent smoke, run autonomous scenarios, modify validators, or change
runtime behavior.

Status: review complete.

## Current-Code Validator Expansion Package

`0.1.7-current-code-validator-expansion` prepares the current-code Agent smoke
contracts for future execution. It is a mixed package that may add dashboard
selectors, extend the Agent smoke validator and result schema, add fixtures and
validator tests, and add a deterministic API evidence helper. It must not run
live Agent smoke, implement archive-summary E2E, add API curl smoke, or change
runtime behavior.

Status: review complete.

## Current-Code Test Execution Package

`0.1.8-current-code-test-execution` executes the current-code contracts that
0.1.7 made runnable. It is a mixed package that first records one live
`dashboard-params-flow` Agent smoke run with helper-generated
`api-summary.json`, then implements the `dashboard-archive-summary`
Playwright E2E scenario. It must not run live `dashboard-invalid-param`, add
API curl smoke, run autonomous scenarios, or change runtime behavior.

Status: ready for review.
