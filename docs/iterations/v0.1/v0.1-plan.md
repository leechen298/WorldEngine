# v0.1 Plan

Status: closeout documented

## Version Name

Runtime Scaffold

## Objective

Record what v0.1 actually contains and which tests currently validate it before
starting v0.2 Recursive World Foundation.

## Completed Capability Areas

- Monorepo scaffold and root dev workflow.
- Runtime state and step API.
- API response envelope.
- Runtime event log timeline.
- World module tree execution.
- World params dashboard and apply API.
- Params validation and dry-run policy.
- Archive snapshots and summaries.
- LLM-style params agent propose-and-apply path.
- Frontend dashboard integration and tests.

## Non-goals

- Recursive WorldCell runtime.
- WorldSpec loader.
- World generation.
- Agent-in-world perception/action loop.
- Agent memory and pseudo-self continuity.
- Reference village world.
- Game surface.

## Closeout Package

## Current Implementation Documentation Package

`0.1.2-current-implementation-docs` records the current backend, frontend,
API, and test implementation map. It is documentation-only and does not change
runtime behavior.

## Post-Closeout Verification Hardening Package

`0.1.3-e2e-agent-acceptance` adds deterministic dashboard E2E tests and an
Agent smoke evidence protocol. It is verification hardening only and does not
expand v0.1 runtime, product, WorldSpec, agent, or village capabilities.
