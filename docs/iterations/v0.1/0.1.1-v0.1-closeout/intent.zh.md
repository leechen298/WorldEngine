# Intent

Status: complete

英文版本：`intent.md`。

## Problem

v0.1 已经有可运行 scaffold，但缺少正式 closeout：没有统一记录 current capability、known
limitations、test evidence 和 next work boundary。

## Goal

建立 v0.1 closeout baseline，让后续 v0.2 work 能基于已验证事实推进。

## Non-goals

- 不新增 runtime features。
- 不修改 backend behavior。
- 不修改 frontend behavior。
- 不实现 WorldCell 或 WorldSpec。
- 不启动 v0.2 schema work。

## Why Now

在进入 v0.2 Recursive World Foundation 前，必须先确认 v0.1 已实现什么、没有实现什么，以及哪些
verification evidence 是真实存在的。

## North Star Alignment

本 package 通过准确记录 v0.1 boundary，避免后续工作把 scaffold 误认为 recursive world runtime 或
village game backend。
