# v0.1 Plan

Status: closeout documented

英文版本：`v0.1-plan.md`。

## Version Name

Runtime Scaffold。

## Objective

记录 v0.1 实际包含的能力，以及哪些 tests 当前验证了这些能力，然后再进入 v0.2 Recursive
World Foundation。

## Completed Capability Areas

- Monorepo scaffold and root dev workflow。
- Runtime state and step API。
- API response envelope。
- Runtime event log timeline。
- World module tree execution。
- World params dashboard and apply API。
- Params validation and dry-run policy。
- Archive snapshots and summaries。
- LLM-style params agent propose-and-apply path。
- Frontend dashboard integration and tests。

## Non-goals

v0.1 不实现：

- WorldCell。
- WorldSpec。
- world generation。
- Agent perception/action/memory loop。
- Agent pseudo-self。
- reference village world。
- game surface。

## Closeout Package

`0.1.1-v0.1-closeout` 运行 verification，记录 evidence，更新 release closeout，并明确 current
capability boundary。

## Current Implementation Documentation Package

`0.1.2-current-implementation-docs` 记录 current backend、frontend、API 和 test implementation
map。它是 documentation-only，不改变 runtime behavior。

## Post-Closeout Verification Hardening Package

`0.1.3-e2e-agent-acceptance` 增加 deterministic dashboard E2E tests 和 Agent smoke evidence
protocol。它只强化 verification，不扩展 v0.1 runtime、product、WorldSpec、agent 或 village
capabilities。

## Codex Test Skills Package

`0.1.4-codex-test-skills` 增加 project-local Codex skills 和 sync tooling，用于一致地运行
E2E 和 Agent smoke workflows。它只提供 workflow guidance，不扩展 runtime、product、WorldSpec、
agent 或 village capabilities。

## Project Agent Workflow Skills Package

`0.1.5-project-agent-workflow-skills` 增加 project-local workflow skills，用于 two-stage
iteration gate：documentation-stage skill 负责起草和 review iteration packages，
implementation-stage skill 只执行已 approve 的 code 或 mixed packages。它只提供 workflow
guidance，不扩展 runtime、product、WorldSpec、agent 或 village capabilities。

Status: review complete。

## Current-Code Test Case Expansion Package

`0.1.6-current-code-test-case-expansion` 定义当前代码对应的 E2E、Agent smoke 和
Codex/test-runner autonomous scenario contracts，然后后续包再实现或执行更多测试。它是
documentation-only，不新增 tests、不执行 live Agent smoke、不运行 autonomous scenarios、不修改
validators，也不改变 runtime behavior。

Status: review complete。

## Current-Code Validator Expansion Package

`0.1.7-current-code-validator-expansion` 为当前代码的 Agent smoke contracts 准备后续可执行
条件。它是 mixed package，可以增加 dashboard selectors、扩展 Agent smoke validator 和 result
schema、增加 fixtures 和 validator tests，并增加 deterministic API evidence helper。它不能执行
live Agent smoke、不能实现 archive-summary E2E、不能增加 API curl smoke，也不能改变 runtime
behavior。

Status: review complete。

## Current-Code Test Execution Package

`0.1.8-current-code-test-execution` 执行 0.1.7 已经准备好的 current-code contracts。它是
mixed package，先用 helper-generated `api-summary.json` 记录一个 live
`dashboard-params-flow` Agent smoke run，然后实现 `dashboard-archive-summary` Playwright
E2E scenario。它不能执行 live `dashboard-invalid-param`、不能增加 API curl smoke、不能运行
autonomous scenarios，也不能改变 runtime behavior。

Status: review complete。
