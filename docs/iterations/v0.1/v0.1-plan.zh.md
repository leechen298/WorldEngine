# v0.1 Plan

Status: closeout complete

英文版本：`v0.1-plan.md`。

## Version Name

Runtime Scaffold。

## Objective

建立 WorldEngine 的 scaffold baseline，用于验证最早的 runtime、event、params、archive、agent-assist
和 dashboard surfaces。

## Completed Capability Areas

- FastAPI backend。
- Vue dashboard。
- root development workflow。
- runtime tick 和 world-time primitives。
- in-memory event log。
- world params flow。
- dry-run validation。
- archive snapshots 和 summaries。
- params-agent endpoint。

## Non-goals

v0.1 不实现：

- WorldCell。
- WorldSpec。
- world generation。
- Agent perception/action/memory loop。
- Agent pseudo-self。
- reference village world。
- game surface。

capability boundary。
