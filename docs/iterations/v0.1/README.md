# v0.1 Runtime Scaffold

Status: closeout documented

## Goal

v0.1 establishes the first working monorepo scaffold for WorldEngine:
backend runtime primitives, frontend dashboard, event timeline, world params,
dry-run validation, archive snapshots/summaries, and root development commands.

## Boundary

v0.1 is not the recursive world foundation. It does not define WorldCell,
WorldSpec, world generation, agent memory, or pseudo-self continuity.
