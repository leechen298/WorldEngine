# Test Plan

## Live Agent Smoke Validation

0.1.8-A must produce a reviewed run directory at:

```text
test-results/agent-smoke/latest/
```

Required files:

- `result.json`
- `operation-log.jsonl`
- `transcript.md`
- `console.log`
- `api-summary.json`
- at least one file under `screenshots/`

`api-summary.json` must be generated by
`tools/testing/agent_smoke_evidence.py collect`, not manually authored.

## E2E Tests

0.1.8-B must add Playwright coverage for:

- `dashboard-archive-summary`

The test must assert archive summary creation and MemoryPanel rendering through
deterministic Playwright assertions. API reads are allowed only inside the test
script as assertion evidence.

## Focused Frontend Tests

Run focused frontend tests touched by archive-summary work, such as:

```bash
cd frontend && pnpm test -- DashboardPage.test.ts MemoryPanel.test.ts
```

If implementation touches additional frontend modules, include their focused
tests in `review.md`.

## Regression Tests

- Existing E2E scenarios must keep passing.
- Existing Agent smoke validator support must accept the new live
  `dashboard-params-flow` run.
- Existing frontend unit coverage for dashboard and MemoryPanel must keep
  passing.

## Commands

Run these after implementation:

```bash
git diff --check
find test-results/agent-smoke/latest -maxdepth 2 -type f | sort
make validate-agent-smoke-result RESULT_DIR=test-results/agent-smoke/latest
make test-e2e
cd frontend && pnpm test -- DashboardPage.test.ts MemoryPanel.test.ts
if git diff --name-only | rg '^(backend/worldengine/|backend/app/)'; then
  echo "Unexpected backend runtime or legacy change"
  exit 1
fi
```

Expected result for the final block: no output.

## Acceptance Criteria

- This package is reviewed before implementation starts.
- 0.1.8-A records only `dashboard-params-flow` live Agent smoke.
- `test-results/agent-smoke/latest/` contains the required raw evidence files.
- Live `api-summary.json` is generated or verified by project tooling.
- `operation-log.jsonl` includes the required `dashboard-params-flow` UI
  targets and no direct API operation records.
- `make validate-agent-smoke-result
  RESULT_DIR=test-results/agent-smoke/latest` exits `0`.
- `dashboard-params-flow` status is updated to `live-smoke-recorded` only
  after validation passes.
- `dashboard-invalid-param` remains validator-supported with no live run
  recorded.
- `dashboard-archive-summary` E2E uses Playwright assertions and MemoryPanel
  selectors.
- Low archive interval env vars are scoped to the Playwright backend web
  server only.
- `make test-e2e` exits `0`.
- `dashboard-archive-summary` status is updated to `implemented` only after
  E2E passes.
- `review.md` records changed files, commands run, test results,
  compatibility review, scope review, unresolved findings, and final
  assessment.

## Not Run

Do not run in 0.1.8:

- live `dashboard-invalid-param`.
- live `dashboard-basic-runtime` unless needed only as an explicit diagnostic
  and not recorded as package completion evidence.
- API curl smoke.
- Codex/test-runner autonomous scenarios or scorecards.
- `dashboard-agent-autotune` E2E.
- `dashboard-timeline-navigation` E2E.
