# Intent

## Problem

0.1.7 made the current-code Agent smoke contracts executable, but the new
`dashboard-params-flow` validator path still has no recorded live run under
`test-results/agent-smoke/latest/`.

The current E2E scenario map also has a contract for
`dashboard-archive-summary`, but no Playwright implementation proves that the
dashboard MemoryPanel displays archive summaries generated by the backend.

Both gaps are execution gaps, not runtime capability gaps. Running them in one
unbounded package would mix live evidence collection, UI test implementation,
and future scenario expansion too loosely.

## Goal

After this package is implemented and reviewed:

- `dashboard-params-flow` has one real live Agent smoke run recorded and
  validated with helper-generated `api-summary.json`.
- `dashboard-archive-summary` is implemented as a deterministic Playwright E2E
  scenario and passes through `make test-e2e`.
- The docs clearly distinguish live Agent smoke evidence, Playwright
  assertion evidence, and forbidden API curl smoke.

## Non-goals

- Do not run live `dashboard-invalid-param`.
- Do not run live `dashboard-basic-runtime` as part of the first 0.1.8
  execution package.
- Do not add API curl smoke.
- Do not hand-author `api-summary.json`.
- Do not change backend runtime semantics or API response contracts.
- Do not modify `backend/worldengine/`.
- Do not implement `dashboard-agent-autotune` or
  `dashboard-timeline-navigation` E2E.
- Do not run Codex/test-runner autonomous scenarios or scorecards.

## Why Now

0.1.6 defined the current-code test map, and 0.1.7 added the missing selectors,
validator support, fixtures, and deterministic API evidence helper. The next
smallest useful step is to prove one non-trivial live Agent smoke path and then
turn the archive-summary E2E contract into runnable Playwright coverage.

## North Star Alignment

This package strengthens evidence around the dashboard projection of runtime
state, events, params, and archive memory. It supports WorldEngine as an
inspectable world runtime and memory substrate without turning the repository
into a game-specific backend or adding agent pseudo-self behavior ahead of the
roadmap.
