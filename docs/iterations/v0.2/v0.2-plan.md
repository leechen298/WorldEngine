# v0.2 Plan

Status: planned / in progress

## Version Name

Recursive World Foundation

## Objective

Move WorldEngine from the v0.1 runtime/event scaffold into a documented,
reviewable foundation for recursive world generation and runtime while keeping
the core repository generic.

## Non-goals

- Do not implement a WorldSpec loader.
- Do not migrate RuntimeEngine to WorldCell.
- Do not implement a runtime bridge.
- Do not implement full world generation.
- Do not implement demo-specific runtime.
- Do not create an external fixture repository or external validation
  repository.
- Do not implement agent inner-world or pseudo-self continuity.
- Do not add vector memory or multi-agent society simulation.
- Do not add concrete external-world fixtures, seed data, roles, locations,
  resources, story rules, or product UI.
