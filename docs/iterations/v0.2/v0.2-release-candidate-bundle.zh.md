# v0.2 Release-Candidate Bundle

状态：`release candidate / not final`

英文版本：`v0.2-release-candidate-bundle.md`

本 bundle 汇总 v0.2 evidence，供 human / ChatGPT review。它不是 final release
声明。Final closeout 仍然保留给 `0.2.12-v0.2-final-closeout`，且必须等待本
bundle review 通过。

## 范围摘要

v0.2 建立 Recursive World Foundation：

- documented north star、product model、roadmap、scope boundaries 和 iteration
  governance。
- generic EntityRef、WorldCell 和 WorldSpec schema foundations。
- additive EventRef 和 optional `Event.refs` event-reference structure。
- generic WorldSpec schema smoke coverage。
- external fixture 和 validation boundaries。
- active `backend/app/` 与 legacy `backend/worldengine/` boundaries。
- evidence、boundary、compatibility 和 release-candidate documentation。

v0.2 不实现 WorldSpec loader、RuntimeEngine-to-WorldCell bridge、runtime
migration、agent-in-world loop、memory 或 pseudo-self continuity、world
generation、projection API、product UI、external fixture repository 或 external
validation repository。
