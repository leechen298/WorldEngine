# v0.2 Release-Candidate Bundle

Status: release candidate / not final

This bundle summarizes v0.2 evidence for human / ChatGPT review. It is not a
final release declaration. Final closeout remains reserved for
`0.2.12-v0.2-final-closeout` after this bundle is approved.

## Scope Summary

v0.2 establishes the Recursive World Foundation:

- documented north star, product model, roadmap, scope boundaries, and
  iteration governance.
- generic EntityRef, WorldCell, and WorldSpec schema foundations.
- additive EventRef and optional `Event.refs` event-reference structure.
- generic WorldSpec schema smoke coverage.
- external fixture and validation boundaries.
- active `backend/app/` and legacy `backend/worldengine/` boundaries.
- evidence, boundary, compatibility, and release-candidate documentation.

v0.2 does not implement a WorldSpec loader, RuntimeEngine-to-WorldCell bridge,
runtime migration, agent-in-world loop, memory or pseudo-self continuity,
world generation, projection API, product UI, external fixture repository, or
external validation repository.

- Runtime behavior: unchanged by 0.2.11.
- Schema behavior and validation behavior: unchanged by 0.2.11.

  0.2.11.

  used as future implementation inputs.

## Known Limitations and Non-goals

- WorldSpec cannot yet be loaded into the runtime.
- RuntimeEngine is not migrated to WorldCell.
- No runtime bridge, generation, projection API, product UI, agent loop,
  memory substrate, or pseudo-self continuity is implemented.
- No external fixture or validation repository is created.
- Historical package tests remain historical evidence; 0.2.11 does not add
  fresh runtime/API/frontend regression evidence.
