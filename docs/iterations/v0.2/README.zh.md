# v0.2 Recursive World Foundation

Status: planned

英文版本：`README.md`。

## Goal

建立 recursive world schema/spec foundation、additive event contract、reference fixture 和 legacy
boundary，同时保留 v0.1 runtime compatibility。

## Version Boundary

v0.2 不能实现 full world generation、village runtime、Agent pseudo-self continuity、game repository
或 RuntimeEngine-to-WorldCell migration。

Tiny Village 可以作为 reference fixture 或 acceptance target，但不能成为 game-specific runtime logic。
