# v0.2 Plan

Status: planned / in progress

英文版本：`v0.2-plan.md`。

## Version Name

Recursive World Foundation。

## Objective

把 WorldEngine 从 v0.1 runtime/event scaffold 推进到可审核的 recursive world generation 和 runtime
foundation，同时保持 core repository generic。

## Non-goals

- 不实现 WorldSpec loader。
- 不迁移 RuntimeEngine 到 WorldCell。
- 不实现 runtime bridge。
- 不实现 full world generation。
- 不实现 demo-specific runtime。
- 不创建 external fixture repository 或 external validation repository。
- 不实现 Agent inner-world 或 pseudo-self continuity。
- 不增加 vector memory 或 multi-agent society simulation。
- 不增加 concrete external-world fixtures、seed data、roles、locations、resources、story rules 或 product UI。

## Detailed Plan Acceptance Gate

在 0.2.6 final output 前，必须确认 `docs/iterations/v0.2/v0.2-plan.md` 和
`docs/iterations/v0.2/v0.2-plan.zh.md` 对 0.2.7 到 0.2.12 每个 package 都包含 full
quasi-package specifications。

如果任一 package 缺少以下字段之一，必须记录为 P2 finding，且不能声称 plan is ready：

- Package name
- Status
- Type
- Goal
- Why this exists
- Inputs / required reading
- Allowed changes
- Forbidden changes
- Expected deliverables
- Expected tests / verification
- Compatibility constraints
- Scope guardrails
- Exit criteria
- Handoff to next package

`README.md` 和 `README.zh.md` 可以只保持 summary-level，但 `v0.2-plan.md` 和 `v0.2-plan.zh.md`
必须足够详细，让后续 Codex planning pass 能生成 next package，而不需要发明 scope。

## Evidence Rule

每个 package 必须在 `review.md` 中记录 commands run、test results、compatibility review、scope review
和 unresolved findings。Docs-only packages 可以跳过 code tests，但必须说明原因。
