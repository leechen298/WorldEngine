# v0.2 计划

状态：`planned / in progress`

英文版本：`v0.2-plan.md`

## 版本名称

Recursive World Foundation。

## 总目标

把 WorldEngine 从 v0.1 的 runtime / event scaffold 推进到可审核的递归世界
generation 与 runtime foundation，同时保持 core repository 的通用性。

## 非目标

- 不实现 WorldSpec loader。
- 不把 RuntimeEngine 迁移到 WorldCell。
- 不实现 runtime bridge。
- 不实现 full world generation。
- 不实现 demo-specific runtime。
- 不创建 external fixture repository 或 external validation repository。
- 不实现 Agent inner-world 或 pseudo-self continuity。
- 不增加 vector memory 或 multi-agent society simulation。
- 不增加 concrete external-world fixtures、seed data、roles、locations、
  resources、story rules 或 product UI。
