# v0.2 Plan

Status: planned

英文版本：`v0.2-plan.md`。

## Version Name

Recursive World Foundation。

## Objective

建立 documentation governance、north star、recursive world schema/spec language、additive event
contract、reference WorldSpec fixture 和 legacy boundary。

## Non-goals

- 不迁移 RuntimeEngine 到 WorldCell。
- 不实现 full world generation。
- 不实现 Agent pseudo-self continuity。
- 不实现 village game runtime。
- 不创建 game repository。
- 不增加 vector memory。
- 不增加 multi-agent society simulation。
