# v0.12 Plan

英文版本：`v0.12-plan.md`。

状态：`closeout complete / PARTIAL`

## Version Name

MVP Agent 连续性与验证自动化

## 目标

通过最小 public Agent continuity loop 和基于 WorldEngine-Validation-Client 的 checker-backed
external validation path，完成 MVP。

## 规划权限边界

本文件是 v0.12 parent roadmap 和 planned package specification。下面的 `0.12.x`
只是路线规格，不授权 code、schema、API、frontend、checker、fixture、provider、
evidence execution 或 Validation Client implementation。

任何 `0.12.x` 子包开始前，都必须先创建或确认该子包完整文档集，并通过 review gate。

## Version Boundaries

v0.12 在子包评审后可以定义或实现：

- public Agent state 和 runtime loop integration。
- observable intent、no-intent、action、wait、rest 和 sleep states。
- 不含 private internals 的 public memory/consolidation summaries。
- read-only 小说式 narrative 和 diagnostic inspection surfaces。
- MVP evidence artifacts 和 scorecards。
- Validation Client handoff contract 和 autonomous validation result schema。
- 区分世界内 Agent 与外部验证 Agent 的 terminology。

v0.12 不实现：

- 真实意识声明。
- evidence 中的 raw/private Agent internals。
- client-owned Agent autonomy。
- WorldEngine 仓库内的 Validation Client code。
- external validation agents 被表述成世界内 Agents。
- concrete game content。

### 0.12.1 Agent Public State And Runtime Loop

Package name: `0.12.1-agent-public-state-and-runtime-loop`

Status: implementation complete / focused verification passed

Type: mixed implementation package

Goal: 增加 minimal public Agent state 和 runtime-integrated loop，让 Agent 可以 observe、
决定 action 或 no-action、execute 并 react to events。

Why this exists: MVP 需要 visible Agent life evidence，而不是一次 client-invoked parameter
action 或 default noop。

Inputs / required reading: v0.11 rule/event evidence、现有 Agent loop、perception、
action adapter、memory context、session runtime、event log 和 redaction rules。

Allowed changes: session Agent records、public state schema、runtime loop hook、
intent/no-intent/action/wait/rest states、action result events、focused tests 和
evidence summaries。

Forbidden changes: 不记录 raw thought，不记录 private goals，不把 client-scripted action
报告为 autonomy，不绕过 rule/event legality，不做完整 personality simulation。

Expected deliverables: public Agent state API/artifact、runtime loop integration、event
reactions，以及证明 actions originate from WorldEngine 的测试。

Expected tests / verification: backend tests 覆盖 observe/no-intent/action、event reaction、
client-scripted-action rejection、redaction 和 runtime compatibility。

Compatibility constraints: 现有 request-driven Agent loop 保持兼容，或通过 additive wrapper 兼容。

Scope guardrails: 如果 Agent action 由 client 控制，而不是 WorldEngine public runtime state，
必须停止。

Exit criteria: 至少一个 Agent 可以在 bounded runtime 中产生 public observe/intent-or-no-intent/
action-or-wait evidence。

Handoff to next package:
`0.12.2-agent-memory-and-rest-consolidation-mvp`。

### 0.12.2 Agent Memory And Rest Consolidation MVP

Package name: `0.12.2-agent-memory-and-rest-consolidation-mvp`

Status: implementation complete / focused verification passed

Type: mixed implementation package

Goal: 增加最小 short-term memory 和 sleep/rest consolidation evidence，同时不假装 personality
或 skills 每个 tick 都变化。

Why this exists: 用户可见 MVP 需要 Agent 会记住并沉淀经验，但第一版可以用 public summaries，
不做深层 cognition。

Inputs / required reading: v0.12 Agent state、现有 memory store、v0.9 continuity/consolidation
evidence、event log、snapshots 和 scope boundaries。

Allowed changes: short-term memory summary records、consolidation cadence、rest/sleep
state records、long-term summary references、public evidence artifacts 和 focused tests。

Forbidden changes: 不记录 raw private memory payloads，不记录 raw thought，不做 automatic
per-tick long-term memory/personality/skill mutation，不把 diagnostic conversation 写入 memory。

Expected deliverables: public memory summaries、rest/sleep records、consolidation artifacts
和 redaction-safe evidence。

Expected tests / verification: backend tests 覆盖 memory summary creation、multi-tick
rest/sleep consolidation、redaction、no per-tick mutation guarantees 和 evidence refs。

Compatibility constraints: 现有 memory APIs 保持 additive-compatible。

Scope guardrails: 如果 evidence 不能区分 short-term summaries、long-term summaries 和
consolidation records，必须停止。

Exit criteria: Agent 可以跨 tick 保留 public memory，并通过 rest/sleep evidence 完成 consolidation。

Handoff to next package:
`0.12.3-narrative-and-diagnostic-inspection-surfaces`。

### 0.12.3 Narrative And Diagnostic Inspection Surfaces

Package name: `0.12.3-narrative-and-diagnostic-inspection-surfaces`

Status: review complete

Type: mixed implementation package

Goal: 提供 lightweight read-only 小说式 narrative projection 和 out-of-world diagnostic
Agent conversation surfaces，用于观察 MVP 行为。

Why this exists: 人需要可读方式判断世界是否合理运行，但这些 surface 不能修改 canonical state。

narrative/diagnostic boundary work、redaction rules 和 projection contracts。

Allowed changes: read-only projection APIs/artifacts、session/tick-range/branch/Agent-focused

Forbidden changes: narrative 不修改 world state，diagnostic conversation 不写入 world
timeline 或 Agent memory，不泄露 raw thought、private memory 或 provider traces。

Expected deliverables: 小说式 narrative projection summary、diagnostic conversation summary、
user-facing query parameters、provenance/redaction fields 和 client-readable artifacts。

Expected tests / verification: backend tests 覆盖 session/tick-range/branch/Agent-focused
projection queries、diagnostic Q&A from public evidence、read-only behavior、redaction、
provenance、mutation rejection 和 event/Agent evidence compatibility。

Compatibility constraints: canonical world state、timeline 和 Agent memory 不得被 projection/
diagnostic inspection 改变。

Scope guardrails: 如果这些 surfaces 变成 gameplay dialogue、canonical story mutation、隐式记录

Exit criteria: 人或 validator 可以通过 readable projections 检查 world/Agent behavior，同时不改变世界。

Handoff to next package:
`0.12.4-validation-client-mvp-evidence-handoff`。

Package name: `0.12.5-full-lifecycle-checker-and-autonomous-validation`

Status: review complete / PARTIAL, fresh external validation BLOCKED

Type: mixed validation package

Goal: 增加或更新 checker scenarios，并通过 WorldEngine-Validation-Client evidence 跑 MVP
full lifecycle。

Why this exists: 只有当 external validation agent 能操作 client、导出 evidence，并且 independent

scorecard summary、只读外部评估者复核 output、外部验证 Agent 与世界内 Agent 的明确 terminology，

### 0.12.6 MVP Release Candidate And Closeout

Status: review complete / PARTIAL

Type: documentation/validation package

Goal: 用 evidence-backed PASS、PARTIAL、BLOCKED 或 FAIL result 关闭 MVP delivery track，
