# Intent

Chinese mirror: `intent.zh.md`.

v0.12 can only start Agent continuity work if v0.11 has honestly handed off a
world that can run, accept bounded guidance, evolve through public rules, and
produce public event/diff/fidelity evidence.

This package exists to record that handoff and to prevent v0.12 from filling
missing Agent behavior with client scripting, narrative projection, or
unverified external validation.

The intended result is a reviewed documentation checkpoint that selects
`0.12.1-agent-public-state-and-runtime-loop` as the next package, with
implementation authorization still closed until `0.12.1` has its own reviewed
contract, technical design, test plan, plan, and review evidence.
