# Intent

英文源文件：`intent.md`。

只有 v0.11 诚实交接一个可以运行、接收 bounded guidance、通过 public rules 演化，并产出
public event/diff/fidelity evidence 的世界后，v0.12 才能开始 Agent continuity work。

本包用于记录该 handoff，并防止 v0.12 用 client scripting、narrative projection 或未经验证的
external validation 来填补缺失的 Agent behavior。

预期结果是一个已评审的文档 checkpoint：选择
`0.12.1-agent-public-state-and-runtime-loop` 作为下一 package，同时 implementation
authorization 仍保持关闭，直到 `0.12.1` 拥有自己的 reviewed contract、technical design、
test plan、plan 和 review evidence。
