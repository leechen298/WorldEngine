# WorldEngine v0.5 Release

Status: final / closeout complete

Chinese mirror: `v0.5.zh.md`.

## Goal

v0.5 closes as the Memory and Self-Continuity Substrate.

The version introduces generic working-memory and episodic-memory contracts,
process-local memory storage, and bounded read-only memory context in Agent
Loop perception while preserving v0.4 action semantics and v0.3 loader/runtime
bridge compatibility.

## Delivered Scope

v0.5 delivered:

- public contract semantics for working memory, episodic memory, relationship
  state, self-summary, reflection records, and personality drift signals.
- additive backend schemas for `MemoryEvidenceRef`, `WorkingMemoryRecord`, and
  `EpisodicMemoryRecord`.
- `InMemoryAgentMemoryStore` as a generic process-local memory substrate.
- additive optional `PerceptionFrame.memory_context` through
  `MemoryContextSummary`.
- bounded read-only working/episodic memory context in the request-scoped Agent
  Loop perception path.
- focused backend memory tests, loop/action compatibility tests, full backend
  regression, and overall validation evidence.
- release-candidate and final closeout documentation.

## Deferred Scope

v0.5 does not implement:

- durable memory persistence.
- public memory read/write/search APIs.
- vector retrieval.
- automatic reflection.
- self-summary generation.
- relationship behavior.
- personality drift action modifiers.
- world generation.
- external validation readiness.
- projection application readiness.
- concrete demo-world content or application-specific backend behavior.
