# WorldEngine v0.3 发布占位文档

状态：`已规划 / 未发布`

## 计划目标

v0.3 的计划目标是 WorldSpec Loader and Runtime Bridge，也就是
WorldSpec 加载器与运行时桥接。

该版本预期让 WorldEngine 加载已验证的通用 WorldSpec 数据，并在保持 v0.1
运行时兼容的前提下，把这些数据连接到运行时上下文。

## 预期范围

v0.3 预期范围包括：

- WorldSpec 加载器契约。
- 最小通用 WorldSpec 加载器。
- 运行时上下文桥接契约。
- 最小可选运行时上下文桥接层。
- 运行时、API、事件、归档、参数、前端可见行为、schema、测试样例和旧路径
  兼容性证据。
- 外部验证样例运行器契约准备。
- 证据索引和兼容性审计。
- 发布候选文档和最终收口文档。

## 非目标

v0.3 不计划实现：

- 世界内 Agent 闭环。
- 记忆或自我连续性基座。
- 世界生成。
- 面向外部产品界面的投影 API。
- 产品 UI 或游戏 UI。
- 具体演示世界样例。
- 具体外部验证世界。
- 外部样例仓库。
- 外部验证仓库。
- 剧情生成。
- NPC 聊天系统。
- 自我意识声明。

## 发布条件

v0.3 只有在以下条件满足后，才能离开“已规划 / 未发布”状态：

- 0.3.0 到 0.3.8 的迭代包证据存在。
- 发布候选评审已获批准。
- 未解决的 P1/P2 问题已解决，或明确记录为阻塞最终收口。
- 任何运行时、API、事件、归档、参数、前端可见行为、schema、测试样例或
  旧路径变更，都有兼容性证据支撑。
- 最终收口评审记录已变更文件、已运行命令、测试结果、兼容性评审、
  范围评审、未解决问题和最终判断。
