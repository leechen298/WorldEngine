# WorldEngine v0.3 Release

状态：`planned / not released`

## Planned Goal

v0.3 计划目标是 WorldSpec Loader and Runtime Bridge。

该版本预期让 WorldEngine 加载 validated generic WorldSpec data，并在保持 v0.1
runtime compatibility 的前提下连接到 runtime context。

## Expected Scope

v0.3 expected scope 包括：

- WorldSpec loader contract。
- minimal generic WorldSpec loader。
- runtime context bridge contract。
- minimal optional runtime context bridge。
- runtime、API、event、archive、params、frontend-facing、schema、fixture 和
  legacy-path compatibility evidence。
- external fixture runner contract readiness。
- evidence and compatibility audit。
- release-candidate 和 final closeout documentation。

## Non-Goals

v0.3 不计划实现：

- Agent-in-World loop。
- memory 或 self-continuity substrate。
- world generation。
- 面向 external product surface 的 projection API。
- product UI 或 game UI。
- concrete demo world fixture。
- concrete external validation world。
- external fixture repository。
- external validation repository。
- story generation。
- NPC chat system。
- self-awareness claims。

## Release Criteria

v0.3 只有在以下条件满足后，才能离开 planned / not released 状态：

- 0.3.0 到 0.3.8 package evidence 存在。
- release-candidate review 已获批准。
- unresolved P1/P2 findings 已解决，或明确阻塞 closeout。
- compatibility evidence 支持任何 runtime、API、event、archive、params、
  frontend-facing、schema、fixture 或 legacy-path changes。
- final closeout review 记录 changed files、commands、test results、
  compatibility review、scope review、unresolved findings 和 final assessment。

## Not A Release Announcement

本文件是 planned v0.3 release documentation placeholder。它不是 release
announcement，也不声明 v0.3 behavior 已交付。
