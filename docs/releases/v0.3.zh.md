# WorldEngine v0.3 发布文档

状态：`final / closeout complete`

## 目标

v0.3 以 WorldSpec Loader and Runtime Bridge，也就是 WorldSpec 加载器与
运行时桥接，完成最终收口。

该版本让 WorldEngine 加载已验证的通用 WorldSpec 数据，并在保持 v0.1 运行时
兼容的前提下，把这些数据连接到可选运行时上下文。

## 已交付范围

v0.3 范围包括：

- WorldSpec 加载器契约。
- 最小通用 WorldSpec 加载器。
- 运行时上下文桥接契约。
- 最小可选运行时上下文桥接层。
- 运行时、API、事件、归档、参数、前端可见行为、schema、测试样例和旧路径
  兼容性证据。
- 外部验证样例运行器契约准备。
- 证据索引和兼容性审计。
- 发布候选文档和最终收口文档。

## 非目标

v0.3 不实现：

- 世界内 Agent 闭环。
- 记忆或自我连续性基座。
- 世界生成。
- 面向外部产品界面的投影 API。
- 产品 UI 或游戏 UI。
- 具体演示世界样例。
- 具体外部验证世界。
- 外部样例仓库。
- 外部验证仓库。
- 剧情生成。
- NPC 聊天系统。
- 自我意识声明。

## 收口证据

v0.3 最终收口基于：

- 0.3.0 到 0.3.8 的迭代包证据。
- 0.3.8 coordination 文件记录的发布候选评审批准。
- 最终收口时没有未解决的 P1/P2 问题。
- `docs/iterations/v0.3/findings.md` 中保留的已接受 P3 交接项。
- v0.3 迭代包评审、证据索引和兼容性审计中的兼容性证据。
- `docs/iterations/v0.3/0.3.8-v0.3-final-closeout/review.zh.md`
  记录的 0.3.8 当前会话文档验证。

## 证据边界

本次收口不声明在 0.3.8 期间重新运行了运行时、API、前端、schema、fixture、
migration、构建、E2E、Agent smoke 或后端回归检查。运行时和兼容性声明依赖
相关实现包运行测试时记录的历史包证据。

v0.4 仍是未来里程碑，只能通过自己的已评审迭代包启动。
