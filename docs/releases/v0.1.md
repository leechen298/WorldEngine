# WorldEngine v0.1 Release Closeout

Status: closeout documented

## Version Summary

v0.1 is the current verified scaffold baseline for WorldEngine.

It establishes:

- monorepo structure.
- FastAPI backend.
- Vue 3 + TypeScript dashboard.
- root development workflow.
- runtime tick and world-time primitives.
- API response envelope.
- in-memory event log.
- event timeline APIs.
- world module tree execution.
- world params API and dashboard surface.
- static and dry-run params validation.
- archive snapshots and summaries.
- LLM-style params agent propose-and-apply service path.

v0.1 is intentionally not the recursive world foundation. That belongs to v0.2.

## Current Capability Boundary

Current v0.1 can:

- start backend and frontend development services through root Make targets.
- expose `GET /health`.
- expose `GET /runtime/state` and `POST /runtime/step`.
- advance runtime ticks and world time.
- append `tick.advanced` and module events.
- expose `GET /world/events` with filters and cursor pagination.
- expose `GET /world/event-steps` grouped by tick.
- execute the default world module tree with heartbeat and counter examples.
- expose `GET /world/params` and `POST /world/params/apply`.
- validate world param patches before applying them.
- dry-run world param patches without polluting the active module state.
- support configurable dry-run validation policy through env and world
  overrides.
- emit `params.applied` events and include current params in runtime event
  payloads.
- create in-memory snapshots at configured tick intervals.
- create in-memory summaries at configured tick intervals.
- expose snapshot and summary list/detail APIs.
- run an LLM-style params agent service that can propose and apply validated
  world parameter patches.
- render frontend controls for runtime stepping, timeline/event inspection,
  world params, patch details, and agent params interactions.

Current v0.1 cannot:

- represent recursive WorldCell structures.
- load a structured WorldSpec.
- generate worlds.
- run agents through a perception/action/memory loop.
- model agent pseudo-self continuity.
- run a village reference world.
- provide a game surface.
- persist full production-grade world state.
- provide a stable external API contract for recursive world consumers.

## Known Limitations

- World and agent schemas are still lightweight placeholders.
- Runtime behavior is not yet driven by WorldSpec.
- Event structure is minimal.
- Persistence is in-memory or placeholder-level.
- `backend/worldengine/` remains legacy code outside the active path.
- Frontend production build currently emits a non-blocking Vite chunk-size
  warning for a 1,513.97 kB JS bundle.
- No live browser smoke, API curl smoke, or E2E suite is recorded for this
  closeout.
