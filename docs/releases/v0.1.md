# WorldEngine v0.1 Release Note

Status: baseline documented

## Version Summary

v0.1 is the current scaffold baseline. It establishes the monorepo, backend
runtime primitives, frontend dashboard entry point, event timeline, params
surface, archive basics, and root development commands.

## Current Capability Boundary

Current v0.1 can:

- start the backend and frontend development services.
- expose FastAPI routes for health, runtime, world, params, archive, and agent
  surfaces.
- advance runtime ticks.
- append runtime events.
- expose event lists and grouped event steps.
- store in-memory snapshots and summaries.

Current v0.1 cannot:

- represent recursive WorldCell structures.
- load a structured WorldSpec.
- generate worlds.
- run agents through a perception/action/memory loop.
- model agent pseudo-self continuity.
- run a village reference world.
- provide a game surface.

## Known Limitations

- World and agent schemas are still lightweight placeholders.
- Runtime behavior is not yet driven by WorldSpec.
- Event structure is minimal.
- Persistence is still scaffold-level.
- `backend/worldengine/` remains legacy code outside the active path.

## Evidence

This document records the capability boundary. It does not rerun tests.
