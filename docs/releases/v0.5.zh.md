# WorldEngine v0.5 发布文档

状态：`final / closeout complete`

英文版本：`v0.5.md`。

## 目标

v0.5 以 Memory and Self-Continuity Substrate，也就是记忆与自我连续性基座，完成最终收口。

该版本引入 generic working-memory 和 episodic-memory contracts、process-local memory
storage，以及 Agent Loop perception 中的 bounded read-only memory context，同时保持
v0.4 action semantics 和 v0.3 loader/runtime bridge compatibility。

## 已交付范围

v0.5 已交付：

- working memory、episodic memory、relationship state、self-summary、reflection
  records 和 personality drift signals 的 public contract semantics。
- `MemoryEvidenceRef`、`WorkingMemoryRecord` 和 `EpisodicMemoryRecord` additive
  backend schemas。
- 作为 generic process-local memory substrate 的 `InMemoryAgentMemoryStore`。
- 通过 `MemoryContextSummary` 暴露的 additive optional
  `PerceptionFrame.memory_context`。
- request-scoped Agent Loop perception path 中的 bounded read-only working /
  episodic memory context。
- focused backend memory tests、loop/action compatibility tests、full backend
  regression，以及 overall validation evidence。
- release-candidate 和 final closeout documentation。

## 延期范围

v0.5 不实现：

- durable memory persistence。
- public memory read/write/search APIs。
- vector retrieval。
- automatic reflection。
- self-summary generation。
- relationship behavior。
- personality drift action modifiers。
- world generation。
- external validation readiness。
- projection application readiness。
- concrete demo-world content 或 application-specific backend behavior。
