# WorldEngine v0.3 Release

Status: planned / not released

## Planned Goal

v0.3 is planned as WorldSpec Loader and Runtime Bridge.

The version is expected to let WorldEngine load validated generic WorldSpec
data and connect it to runtime context while preserving v0.1 runtime
compatibility.

## Expected Scope

Expected v0.3 scope includes:

- WorldSpec loader contract.
- minimal generic WorldSpec loader.
- runtime context bridge contract.
- minimal optional runtime context bridge.
- runtime, API, event, archive, params, frontend-facing, schema, fixture, and
  legacy-path compatibility evidence.
- external fixture runner contract readiness.
- evidence and compatibility audit.
- release-candidate and final closeout documentation.

## Non-Goals

v0.3 is not planned to implement:

- Agent-in-World loop.
- memory or self-continuity substrate.
- world generation.
- projection API for external product surfaces.
- product UI or game UI.
- concrete demo world fixture.
- concrete external validation world.
- external fixture repository.
- external validation repository.
- story generation.
- NPC chat system.
- self-awareness claims.

## Release Criteria

v0.3 can only move out of planned / not released status after:

- 0.3.0 through 0.3.8 package evidence exists.
- release-candidate review is approved.
- unresolved P1/P2 findings are resolved or explicitly block closeout.
- compatibility evidence supports any runtime, API, event, archive, params,
  frontend-facing, schema, fixture, or legacy-path changes.
- final closeout review records changed files, commands, test results,
  compatibility review, scope review, unresolved findings, and final
  assessment.
