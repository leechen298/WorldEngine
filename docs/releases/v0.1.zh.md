# WorldEngine v0.1 Release Closeout

Status: closeout documented

英文版本：`v0.1.md`。

## Version Summary

v0.1 是当前已验证的 WorldEngine scaffold baseline。

它建立了：

- monorepo structure。
- FastAPI backend。
- Vue 3 + TypeScript dashboard。
- root development workflow。
- runtime tick 和 world-time primitives。
- API response envelope。
- in-memory event log。
- event timeline APIs。
- world module tree execution。
- world params API 和 dashboard surface。
- static 与 dry-run params validation。
- archive snapshots 和 summaries。
- LLM-style params agent propose-and-apply service path。

v0.1 有意还不是 recursive world foundation。那属于 v0.2。

## Current Capability Boundary

当前 v0.1 可以：

- 通过 root Make targets 启动 backend 和 frontend development services。
- 暴露 `GET /health`。
- 暴露 `GET /runtime/state` 和 `POST /runtime/step`。
- 推进 runtime ticks 和 world time。
- 追加 `tick.advanced` 和 module events。
- 暴露带 filters 和 cursor pagination 的 `GET /world/events`。
- 暴露按 tick 分组的 `GET /world/event-steps`。
- 执行包含 heartbeat 与 counter 示例的 default world module tree。
- 暴露 `GET /world/params` 和 `POST /world/params/apply`。
- 应用前验证 world param patches。
- dry-run world param patches 且不污染 active module state。
- 通过 env 和 world overrides 支持 configurable dry-run validation policy。
- emit `params.applied` events，并在 runtime event payloads 中包含 current params。
- 按配置 tick intervals 创建 in-memory snapshots。
- 按配置 tick intervals 创建 in-memory summaries。
- 暴露 snapshot 和 summary list/detail APIs。
- 运行 LLM-style params agent service，提出并应用经过验证的 world parameter patches。
- 渲染 runtime stepping、timeline/event inspection、world params、patch details 和 agent params
  interactions 的 frontend controls。

当前 v0.1 不能：

- 表达 recursive WorldCell structures。
- 加载 structured WorldSpec。
- 生成 worlds。
- 通过 perception/action/memory loop 运行 Agent。
- 建模 Agent pseudo-self continuity。
- 运行 village reference world。
- 提供 game surface。
- 持久化 production-grade world state。
- 为 recursive world consumers 提供 stable external API contract。

## Known Limitations

- World 和 Agent schemas 仍是 lightweight placeholders。
- Runtime behavior 还不是由 WorldSpec 驱动。
- Event structure 是 minimal。
- Persistence 是 in-memory 或 placeholder-level。
- `backend/worldengine/` 仍是 active path 之外的 legacy code。
- Frontend production build 当前会为 `1,513.97 kB` JS bundle 输出 non-blocking Vite chunk-size
  warning。
- 本 closeout 未记录 live browser smoke、API curl smoke 或 E2E suite。
