# WorldEngine v0.2 Release Notes

Status: planned

英文版本：`v0.2.md`。

## Version Theme

v0.2 is Recursive World Foundation.

它不是 external application runtime，也不是 game backend iteration。

## Goal

建立 WorldEngine 表达 recursive world generation 与 runtime 的基础 contract：

- documentation governance。
- WorldCell schema/spec foundation。
- WorldSpec structured representation。
- additive Event contract extension。
- generic WorldSpec schema smoke validation。
- external fixture 和 validation boundaries。
- legacy boundary cleanup。

## Capability Target

v0.2 完成后应该能够：

- 描述 WorldEngine 的 north star 和 product boundaries。
- 定义 minimal recursive WorldCell abstraction。
- 定义 generated/loadable world 的 WorldSpec shape。
- 扩展 Event contract 且保持 backward compatibility。
- validate generic WorldSpec schema smoke behavior。
- 定义 external fixture 和 validation boundaries。
- 明确 `backend/app/` 是 active path，`backend/worldengine/` 是 legacy path。

## Non-goals

v0.2 不会：

- migrate RuntimeEngine to WorldCell。
- implement full world generation。
- implement Agent pseudo-self continuity。
- implement demo-specific runtime。
- create a game repository。
- add vector memory。
- add multi-agent society simulation。

## Closeout Requirements

Release closeout 必须包含：

- completed iteration packages。
- changed files。
- commands run。
- test results。
- compatibility review。
- scope review。
- known limitations。
- recommended next work。
