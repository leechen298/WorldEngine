# WorldEngine v0.2 Release

状态：`final / closeout complete`

英文版本：`v0.2.md`

## 版本摘要

v0.2 是 Recursive World Foundation closeout。0.2.11 release-candidate bundle
已通过 0.2.12 implementation gate 的 final review for closeout，且没有
unresolved P1/P2 findings。

本文件记录 v0.2 的 final documentation status。它不声明超出已 review 的 v0.2
packages historical evidence 之外的新 runtime、schema、API、frontend、
fixture、migration 或 test behavior。

## Foundation Pieces

v0.2 已有 review evidence 支撑：

- project north star 和 documentation governance。
- EntityRef、WorldCell 和 WorldSpec schema/spec concepts。
- EventRef 和 optional Event.refs additive event structure。
- generic WorldSpec schema smoke validation。
- external fixture 和 validation boundaries。
- redacted validation report template。
- active `backend/app/` 和 legacy `backend/worldengine/` boundary documentation。
- iterative automation workflow 和 final-review handoff。
- evidence index、boundary audit、compatibility review 和 release-candidate
  bundle。

## Package Status

- 0.2.1 through 0.2.3：review complete。
- 0.2.4：historical artifact，已被 0.2.5 superseded。
- 0.2.5 through 0.2.12：review complete。
- 0.2.11：release-candidate bundle complete。
- 0.2.12：final closeout complete。

## Capability Boundary

v0.2 可以 claim evidence for：

- 描述 WorldEngine 的 north star 和 product boundaries。
- 定义 minimal recursive WorldCell abstraction。
- 定义 generated/loadable world 的 WorldSpec shape。
- 扩展 Event contract 并保持 backward compatibility。
- validate generic WorldSpec schema smoke behavior。
- 定义 external fixture 和 validation boundaries。
- 明确 `backend/app/` 是 active path，`backend/worldengine/` 是 legacy path。
- 提供 final closeout evidence 供 review。

v0.2 不声明它可以：

- 在 RuntimeEngine 中运行 WorldCell。
- 把 WorldSpec 加载到 runtime。
- 从 prompt 生成 worlds。
- 形成 agent pseudo-self。
- 运行 demo-specific application behavior。
- 提供 product client。

## 已知限制

- WorldSpec loading 和 runtime bridge behavior 未实现。
- RuntimeEngine 保持 v0.1 scaffold，未迁移到 WorldCell。
- Agent-in-world loop、memory、pseudo-self continuity、generation、projection
  API、product UI、external fixture repository 和 external validation repository
  都是 future scope。
- 当前 0.2.11 verification 是 documentation-only。它没有重跑 backend、
  frontend、API smoke、E2E、Agent smoke、runtime、schema execution、fixture 或
  migration tests。
- 0.2.12 verification 是 documentation-only。它没有重跑 backend、frontend、API
  smoke、E2E、Agent smoke、runtime、schema execution、fixture 或 migration
  tests。
- `v0.2-P3-003` 被接受为 non-blocking v0.3 handoff，要求 future bridge
  behavior changes 前提供 current-session compatibility evidence。

## Handoff

v0.3 只能通过单独 review 过的 iteration package 启动。第一个 v0.3 bridge
package 必须在改变 runtime、API、event、archive、params、frontend-facing 或
legacy-path behavior 前产生 current-session compatibility evidence。
