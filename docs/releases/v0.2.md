# WorldEngine v0.2 Release Draft

Status: release candidate / not released / not final

## Version Summary

v0.2 is the Recursive World Foundation release candidate. It is not final
release status.

This document is a release draft, not a release announcement. Final closeout
will happen only after `0.2.12-v0.2-final-closeout`, and only after the
0.2.11 release-candidate bundle passes human / ChatGPT final review.

## Candidate Foundation Pieces

v0.2 has review evidence for:

- project north star and documentation governance.
- EntityRef, WorldCell, and WorldSpec schema/spec concepts.
- EventRef and optional Event.refs as additive event structure.
- generic WorldSpec schema smoke validation.
- external fixture and validation boundaries.
- redacted validation report template.
- active `backend/app/` and legacy `backend/worldengine/` boundary
  documentation.
- iterative automation workflow and final-review handoff.
- evidence index, boundary audit, compatibility review, and release-candidate
  bundle.

## Package Status

- 0.2.1 through 0.2.3: review complete.
- 0.2.4: historical artifact, superseded by 0.2.5.
- 0.2.5 through 0.2.10: review complete.
- 0.2.11: release-candidate bundle complete and final review requested.
- 0.2.12: planned final closeout after approval.

## Candidate Capability Boundary

v0.2 can claim evidence for:

- define the project north star and documentation governance.
- define WorldCell and WorldSpec schema/spec concepts.
- validate generic WorldSpec schema smoke behavior.
- define external fixture and validation boundaries.
- express recursive world structure at the spec layer.
- preserve existing runtime behavior.
- mark the active and legacy backend boundaries.
- provide release-candidate evidence for review.

v0.2 does not claim it can:

- run WorldCell in RuntimeEngine.
- load WorldSpec into runtime.
- generate worlds from a prompt.
- form agent pseudo-self.
- run demo-specific application behavior.
- provide a product client.

## Known Limitations

- WorldSpec loading and runtime bridge behavior are not implemented.
- RuntimeEngine remains the v0.1 scaffold and is not migrated to WorldCell.
- Agent-in-world loop, memory, pseudo-self continuity, generation,
  projection API, product UI, external fixture repository, and external
  validation repository are future scope.
- Current 0.2.11 verification is documentation-only. It does not rerun
  backend, frontend, API smoke, E2E, Agent smoke, runtime, schema execution,
  fixture, or migration tests.
- `v0.2-P3-003` remains open as a v0.3 handoff requiring current-session
  compatibility evidence before future bridge behavior changes.
