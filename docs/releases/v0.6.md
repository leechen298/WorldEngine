# WorldEngine v0.6 Release

Status: final / closeout complete, with post-closeout reliability repair
complete

Chinese mirror: `v0.6.zh.md`.

## Goal

v0.6 closes as World Generation v1.

The version adds generic world-generation contracts, deterministic template
generation, structured generation plan compilation, AI-assisted redacted plan
import boundaries, preview/regeneration/runtime-readiness APIs, and a dashboard
generation preview. It preserves the v0.5 memory substrate, v0.4
Agent-in-World loop, and v0.3 loader/runtime bridge compatibility.

## Delivered Scope

v0.6 delivered:

- generic `WorldTemplate`, `TemplateCell`, `GenerationPlan`, and `PlanCell`
  contracts.
- deterministic generic `WorldSpec` generation from reviewed templates and
  structured plans.
- validation diagnostics for duplicate cells, duplicate entity refs,
  entity-kind constraints, child-count constraints, JSON compatibility, and
  unsupported generation versions.
- AI-assisted plan import as structured data only, with redacted provenance
  requirements and sensitive metadata rejection.
- public generation preview, regeneration, and runtime-readiness API routes
  under `/world/generation`.
- bounded public `worldspec_preview` metadata with raw request and sensitive
  provenance redaction.
- dashboard generation preview flow with success, diagnostics failure, and
  runtime-readiness display paths.
- 0.6.11 post-closeout reliability repair for failed-generation seed digest
  fallback, sensitive imported-plan provenance coverage, and token-usage metric
  compatibility.
- release-candidate, final closeout, and post-closeout reliability evidence.

## Deferred Scope

v0.6 does not implement:

- recursive `WorldCell` execution as active runtime state.
- persistence for generated worlds, runtime state, memory, archive, or events.
- live AI provider integration or prompt execution.
- subjective generation-quality approval.
- external validation readiness.
- projection application readiness.
- full product readiness.
- new live Agent smoke execution or full autonomous runner/full-suite PASS.
- concrete demo worlds, maps, characters, resources, story rules, or
  application-specific backend behavior.
