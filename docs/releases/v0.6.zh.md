# WorldEngine v0.6 发布文档

状态：`final / closeout complete`，且 post-closeout reliability repair 已完成

英文版本：`v0.6.md`。

## 目标

v0.6 以 World Generation v1，也就是世界生成第一版，完成最终收口。

该版本新增 generic world-generation contracts、deterministic template
generation、structured generation plan compilation、AI-assisted redacted plan
import boundaries、preview/regeneration/runtime-readiness APIs，以及 dashboard
generation preview。它保留 v0.5 memory substrate、v0.4 Agent-in-World loop 和
v0.3 loader/runtime bridge compatibility。

## 已交付范围

v0.6 已交付：

- generic `WorldTemplate`、`TemplateCell`、`GenerationPlan` 和 `PlanCell`
  contracts。
- 从已评审 templates 和 structured plans 生成 deterministic generic `WorldSpec`。
- duplicate cells、duplicate entity refs、entity-kind constraints、
  child-count constraints、JSON compatibility 和 unsupported generation versions
  的 validation diagnostics。
- 仅作为 structured data 导入 AI-assisted plan，并要求 redacted provenance，
  拒绝 sensitive metadata。
- `/world/generation` 下的 public generation preview、regeneration 和
  runtime-readiness API routes。
- 有界 public `worldspec_preview` metadata，并移除 raw request 与 sensitive
  provenance。
- dashboard generation preview flow，覆盖 success、diagnostics failure 和
  runtime-readiness display paths。
- 0.6.11 post-closeout reliability repair，修复 failed-generation seed digest
  fallback、sensitive imported-plan provenance coverage 和 token-usage metric
  compatibility。
- release-candidate、final closeout 和 post-closeout reliability evidence。

## 延期范围

v0.6 不实现：

- 把递归 `WorldCell` 作为 active runtime state 执行。
- generated worlds、runtime state、memory、archive 或 events 的持久化。
- live AI provider integration 或 prompt execution。
- subjective generation-quality approval。
- external validation readiness。
- projection application readiness。
- full product readiness。
- 新 live Agent smoke execution 或 full autonomous runner/full-suite PASS。
- concrete demo worlds、maps、characters、resources、story rules 或
  application-specific backend behavior。
