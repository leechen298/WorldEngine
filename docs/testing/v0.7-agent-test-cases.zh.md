# v0.7 Agent 测试用例分册

Status: proposed / not executed
Date: 2026-06-02
Parent plan: `docs/testing/v0.7-overall-test-plan.zh.md`

本分册定义 v0.7 的 Agent smoke、minimal autonomous saved-result validation、
以及用户定义的完整 Agent 自主测试用例。这里的 Agent 指 Codex/test-runner 作为测试执行者，
不是 WorldEngine 世界里的 in-world Agent。

## 定义

完整 Agent 自主测试采用普通用户视角：

- Codex/test-runner 拿到目标后自主决定步骤。
- 可以操作 dashboard。
- 可以调用公开产品/API 合同的一部分，例如 `/runtime/state`、`/world/events`、
  `/world/params`、`/world/agent/loop/step`、`/world/generation/*`。
- 可以运行公开 checker CLI。
- 必须记录 raw artifacts。
- PASS 必须来自 deterministic checker、scorecard checker 或未来 full autonomous suite checker。

当前仓库已有的是 minimal saved-result checker；它不是 full autonomous runner。
当前 saved-result checker 仍把 direct API operation 作为 invalid Agent operation，
因此完整用户式自主测试需要 schema/checker 扩展后才能自动判 PASS。

## Minimal Autonomous Saved-Result 用例

Saved-result autonomous 只验证一个已保存 result directory 满足 scorecard/checker。
当前 checker 的能力边界是协议/结构门禁：scenario/status/verdict source、required UI targets、
UI/CLI-only operation log、score_items 全部 `pass` 且 evidence 非空、artifact path 可读、
scorecard summary 匹配、无 unresolved P1。它不解析 evidence 内容，也不通过 API/state 独立证明
params applied、invalid no-mutation、Auto-Tune patch semantics 或 timeline row 语义。

`make validate-agent-autonomous-fixtures` 当前只有 `autonomous-dashboard-basic-runtime` 正例 fixture；
其他 scenario ID 被 checker 支持，但若没有对应 positive fixture 或场景级 checker，只能证明
result directory 的协议和声明型 scorecard evidence 合格。

## Manual Observation Boundary

Screenshots、transcripts、console notes 和人工观察只能解释 failure、blocker、skipped
或 out-of-scope。它们不能成为 E2E、Agent smoke、autonomous、external suite、
projection readiness 或 product readiness 的 PASS 来源。
