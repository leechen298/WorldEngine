## Agent Smoke Note

This package verified the Agent smoke protocol and deterministic checker through
fixtures. A live Agent smoke run was not executed.

When a live Agent smoke run is executed, preserve the latest raw evidence under
`test-results/agent-smoke/latest/` for commit/push review. Historical
timestamped runs remain local-only by default.

A live Agent smoke run must not be reported as passed unless a real result
directory is validated by:

```bash
make validate-agent-smoke-result RESULT_DIR=<run-dir>
```
