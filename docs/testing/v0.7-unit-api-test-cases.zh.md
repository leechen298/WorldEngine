# v0.7 单元 / 后端 API 测试用例分册

Status: proposed / not executed
Date: 2026-06-02
Parent plan: `docs/testing/v0.7-overall-test-plan.zh.md`

本分册是 v0.7 测试方案的 unit、checker、CLI 和后端 API/integration 用例清单。
它不是验证结果，不声明任何测试已经通过。

## 范围

本分册覆盖：

- v0.7 redacted external validation report checker。
- v0.7 readiness manifest checker。
- v0.7 projection read-model checker。
- Agent smoke / autonomous saved-result checker protocol。
- v0.3-v0.6 loader、runtime、event、params、Agent Loop、memory、generation 兼容性。
- public JSON schema 与 checker 语义权威关系。

E2E、Agent smoke live run 和 full autonomous runner 不属于本分册；它们分别见：

- `docs/testing/v0.7-e2e-test-cases.zh.md`
- `docs/testing/v0.7-agent-test-cases.zh.md`

## E2E / Agent 不可替代理由

- E2E 只能覆盖少量用户路径，不能穷尽 checker 的 JSON shape、redaction 字符串扫描、CLI exit code 和 invalid fixture。
- Agent smoke 或 autonomous 结果目录只能证明一次记录的 evidence 被 checker 接受，不能替代 schema/checker 边界测试。
- 后端 focused tests 能验证 no-mutation、API envelope、memory store isolation、generation import redaction 等细粒度语义。
- full backend regression 是 blast-radius sweep，不替代 UT-V07-001 到 UT-V07-019 的定向覆盖。
