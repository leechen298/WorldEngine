# v0.7 E2E 测试用例分册

Status: proposed / not executed
Date: 2026-06-02
Parent plan: `docs/testing/v0.7-overall-test-plan.zh.md`

本分册定义 v0.7 整体测试方案中的 Browser E2E 和 API-level Playwright 用例。
它不是 E2E 执行结果；PASS 只能来自当前会话 Playwright assertion 退出码。

## 执行入口

全量 E2E：

```bash
make test-e2e
```

Focused E2E：

```bash
cd frontend && pnpm exec playwright test e2e/dashboard.spec.ts
cd frontend && pnpm exec playwright test e2e/agent-loop.spec.ts
cd frontend && pnpm exec playwright test e2e/dashboard-generation.spec.ts
```

## Local Server / Artifact 要求

- API server 默认 URL：`http://127.0.0.1:8000`，可用 `E2E_API_BASE_URL` 覆盖。
- Frontend server 默认 URL：`http://127.0.0.1:5173`，可用 `E2E_APP_BASE_URL` 覆盖。
- Archive/summary 场景依赖 Playwright backend webServer 的
  `WORLD_SUMMARY_INTERVAL_TICKS=2 WORLD_SNAPSHOT_INTERVAL_TICKS=2`。
- `reuseExistingServer: !CI`。复用本地 server 时，结果报告必须记录 branch、commit、
  server URL、runtime/params/event state 是否清楚。
- E2E 以 serial state 运行，会改变 runtime、params、events、summary；结果报告不能假设
  所有 spec 从空状态开始。
- Artifact roots:
  - `test-results/e2e/html-report/index.html`
  - `test-results/e2e/artifacts/`
  - failure screenshot and trace when retained by Playwright.

## 结果记录要求

每次 E2E 结果摘要必须记录：

- exact command。
- branch、commit、工作树状态。
- 是否复用 server。
- Playwright exit status。
- pass/fail count。
- HTML report path。
- failure artifacts path。
- failed/skipped tests and reason。
- 是否包含 E2E-V07-014；若没有，应记录为 planned gap，而不是当作已通过 API-level E2E。
