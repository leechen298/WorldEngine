# Frontend (Vue 3 + TypeScript)

This folder contains the V1 dashboard scaffold for WorldEngine.

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

The app runs at `http://localhost:5173` by default.

## Environment

Set `VITE_API_BASE_URL` (default: `http://localhost:8000`) to point at the backend API.

## Current Page

- `DashboardPage` with placeholder panels and backend health status.
